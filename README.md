# KINDAI GROWTH — MVP アプリ

近畿大学生向け「努力が見える・続く・得をする」継続支援コミュニティアプリの MVP 実装。
事業計画書（`kindai-growth-app fable5/business-plan/03_サービス企画書.md`）と設計画像を基に、
**RPGとして成立する仕組み** と **ランキングが成立する仕組み** を最低限の機能として実装しています。

## 実装した機能（MVP）

### RPG成立要素
- **レベル / EXP**：ミッション達成でEXP獲得 → 閾値到達でレベルアップ（演出付き）
- **4ステータス**：体力（運動）/ 知力（勉強）/ 活力（生活習慣）/ 魅力（振り返り）が努力で上昇
- **連続日数（ストリーク）** と累計達成日数
- **2種通貨**：SP（シーズンPt）/ ポイント（協賛クーポン用）
- **デイリー報酬**・イベントバナー

### ランキング成立要素
- **学内ランキング**（近畿大学）：週間 / 月間、学部別フィルタ、表彰台(Top3)、自分の順位ハイライト
- **フレンドランキング**：週間SPでフレンドと競争
- 自分の記録SPが集計され実際にランキングへ反映される

### 努力の記録ループ
デイリーミッション一覧 → タイマー実行 → レビュー（達成度★・コメント）→ 報酬獲得 → ステータス/レベル反映

### その他
- 振り返り（週間SPグラフ・記録履歴・KPI）
- マイページ（ステータス詳細・サマリ）
- 協賛店舗クーポン引き換え（B2B2Cモデルの体験）
- 状態は localStorage に永続化（リロードしても継続）

## 技術
- Vite + React 18 + TypeScript（クロスプラットフォーム前段としてのWeb実装）
- 状態管理：React Context + localStorage（バックエンド不要のデモ）

## 起動方法

```bash
cd kindai-growth-app
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開く（モバイル幅 430px を想定したレイアウト）。

## 画面構成
| 画面 | 内容 |
|---|---|
| ホーム | プロフィール・アバター・ステータス・ミッションCTA・イベント |
| デイリーミッション | 3ミッション・達成状況・ボーナス |
| ミッション実行 | タイマー |
| レビュー | 達成度★・コメント・報酬確定 |
| ランキング | 学内/フレンド × 週間/月間 × 学部別 |
| 振り返り | 週間グラフ・KPI・記録履歴 |
| マイページ | ステータス詳細・サマリ・リセット |
| 報酬 | 協賛店舗クーポン引き換え |
