# アバター画像の置き場所

ここ（`public/`）に以下のファイル名で画像を置くと、アプリのアバターが自動でその画像に切り替わります。
置かない場合は簡易SVGアバターが表示されます（アプリは問題なく動きます）。

| ファイル名 | 使われる場所 | 推奨サイズ・形式 |
|---|---|---|
| `hero-avatar.png` | ホーム／マイページの大きなキャラクター | 縦長 3:4（例 600×800px）・PNG or JPG |
| `mini-avatar.png` | ホーム上部の丸いアイコン | 正方形 1:1（例 200×200px）・PNG or JPG |

## 手順
1. 使いたいキャラクター画像を用意（デザインモックの人物イラストなど）。
2. 上記のファイル名にリネームして、この `public/` フォルダに保存。
3. ブラウザを再読み込み（`npm run dev` 中なら自動反映）。

> 画像は `hero-img` / `avatar-sm` の枠に `object-fit: cover` で表示されます。
> 人物が枠からはみ出す場合は、画像側で余白を調整してください。
