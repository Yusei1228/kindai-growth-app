# アバター画像の置き場所

ここ（`public/`）に **`hero-avatar.png`** を1枚置くだけで、アプリのアバターが
その画像に切り替わります（ホームの大きなキャラクターも、上部の丸アイコンも同じ画像から表示）。
置かない場合は簡易SVGアバターが表示されます（アプリは問題なく動きます）。

| ファイル名 | 使われる場所 | 推奨 |
|---|---|---|
| `hero-avatar.png` | ホーム/マイページの大画像＋上部の丸アイコン | 縦長・全身イラストでOK（例 900×1600px）PNG/JPG |

## 手順
1. 使いたいキャラクター画像（全身イラストでOK）を用意。
2. ファイル名を `hero-avatar.png` にリネームして、この `public/` フォルダに保存。
3. ブラウザを再読み込み（`npm run dev` 中なら自動反映）。

> - 大画像は上寄せ（`object-position: center top`）、丸アイコンは顔まわり（`center 12%`）を表示します。
> - 顔の位置が合わない場合は、`src/components/Avatar.tsx` の `objectPosition` の数値を調整するか、
>   画像側で顔の位置を上寄りにトリミングしてください。
> - JPGを使う場合もファイル名は `hero-avatar.png` のままでOK（拡張子偽装でも表示されますが、
>   気になる場合は Avatar.tsx の `src` を `/hero-avatar.jpg` に変えてください）。
